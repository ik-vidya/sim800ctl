# Как участвовать

## Проблемы

Нашли баг — открывайте issue. Приложите:

- Версию утилиты (`sim800ctl version`).
- Модель и прошивку модема:

      sim800ctl -p PORT exec 'AT+CGMM'
      sim800ctl -p PORT exec 'AT+CGMR'

- Отчёт диагностики:

      sim800ctl -p PORT diagnose --all-safe --report report.json

  и приложите файл `report.json`.

## Pull requests

Приветствуются. Требования:

1. Код покрыт тестами (`*_test.go`).
2. `go vet ./...` и `go test ./...` проходят.
3. Протестировано на реальном модеме — опишите в описании PR.
4. Комментарии в коде — на русском (стиль проекта).
5. Коммиты подписаны trailer'ом `Assisted-by:` (см. ниже).

## Использование AI-ассистентов

Не запрещено. Требуется:

- Указывать `Assisted-by: <tool>:<model>` в трейлере коммита,
  если код писался с помощью AI.
- Автор PR лично отвечает за каждую строку: если рецензент
  спросит «почему это работает так?», ответ «AI написал» не
  принимается.
- Код, который автор не может объяснить, будет отклонён.

Это правило — следствие здравого смысла: качество важнее скорости.

## Установка hook для Assisted-by

    ./scripts/setup-hooks.sh

Hook будет автоматически добавлять trailer `Assisted-by: DeepSeek chat`
в каждый коммит, если его ещё нет.

## Стиль

- Идиоматичный Go, `gofmt -s`, `go vet`.
- Комментарии — на русском, идентификаторы — на английском.
- Никакого CGO.
- Graceful shutdown, context везде, где нужен.
